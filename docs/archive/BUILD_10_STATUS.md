## ⚙️ AI CONFIGURATION

### Environment Variables:
```bash
AI_ENABLED=true          # Enable AI narrator (default: true)
AI_MODEL=distilgpt2      # Model to use (default: distilgpt2)
```

### Model Options:
- `distilgpt2` - 82 MB, fast, recommended (default)
- `gpt2` - 548 MB, better quality
- `facebook/opt-125m` - 250 MB, optimized

### Performance:
- First load: ~2-5 seconds (downloads model)
- Subsequent: ~1-2 seconds per narrative (cached)
- CPU-only (no GPU needed)
